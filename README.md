# HyRest.Abstractions

Core abstractions and interfaces for the HyRest library ecosystem.

## Overview

HyRest.Abstractions provides the foundational contracts, interfaces, and base types used throughout the HyRest suite. This library defines the core abstractions for Hyland client integration, identity and authentication, and OnBase operations.

## Key Components

- **HylandClient**: Core client abstractions for Hyland service integration
- **Identity**: Authentication and identity management interfaces
- **OnBase**: OnBase-specific abstractions and contracts

## Usage

This library is primarily used by other HyRest packages and should be referenced when creating extensions or custom implementations for HyRest functionality.
